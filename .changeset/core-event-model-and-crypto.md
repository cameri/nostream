feat(core): implement the event model, NIP-01 filters, crypto and NIP semantics

`nostream-core` gains the 32-byte `EventId`/`Pubkey` and 64-byte `Signature` newtypes
with the schema's hex rules in the type, the canonical serialization and SHA-256 event
id, BIP-340 Schnorr signing and verification, the NIP-01 filter matcher and the zod
filter schema's rules, subscription normalisation, NIP-13 difficulty, NIP-40 expiration,
NIP-44 v2, reference-time and replaceable-precedence helpers, and the NIP-77
reconciliation engine over the `negentropy` crate. Settings keep operator pubkey text in
a separate `SettingsPubkey`.

The TypeScript tree is untouched: no `src/` or `test/` file changes, so the published
package has no user-visible change. The differential fixture
(`crates/nostream-core/tests/fixtures/ts-events.json`) is the capture's own measurement
of 1,000 events and 50 negative events, regenerated by
`crates/nostream-core/tests/capture/gen-ts-events.mjs` at `242a3001`. Decisions and the
negentropy divergences are recorded in `docs/rewrite/decisions/0002-core-crypto-and-negentropy.md`.
