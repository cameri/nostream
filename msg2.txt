fix(cli): gate the ancestry check and pin the non-Unix refusal

Greptile's first finding: `refuse_swappable_ancestry` reads
`metadata.permissions().mode()` and was not gated, so Rust still
type-checked it on Windows and the build still failed.

Greptile's second: the Unix contract lived in tests that would compile
on every platform and assert Unix behaviour. `migrate_cli.rs` now
carries `#![cfg(unix)]` for the whole file (which is what the four
per-test gates were reaching for), and `migrate_cli_unsupported.rs`
pins the refusal where the copy cannot run. The Windows job runs that
test too, so the refusal is executed on the platform it describes
rather than merely built.
